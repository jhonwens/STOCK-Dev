# 智能分析 Agent 使用指南

## 入口

侧边栏 → 🤖 智能分析（路由 `/ai-analyst`）

## 基本操作

1. **新建会话**: 点击左侧"➕ 新建会话"按钮
2. **发送消息**: 在底部输入框输入问题，按 Enter 发送（Shift+Enter 换行）
3. **重命名会话**: 双击会话名 → 进入编辑模式 → Enter 确认 / Esc 取消
4. **置顶/删除**: 悬停会话 → 点击 📌 置顶 或 🗑️ 删除
5. **切换会话**: 点击左侧会话列表中的任意会话
6. **示例问题**: 点击输入框上方的 💡 示例问题 按钮

## 示例问题

| 类别 | 示例 |
|------|------|
| 个股 | "688256 现在能买吗" |
| 个股 | "分析 300750 宁德时代" |
| 持仓 | "我的持仓怎么样" |
| 候选推荐 | "推荐 5 只长期价值股" |
| 行业 | "半导体行业前景如何" |
| 市场 | "今天大盘情绪怎样" |
| 查询 | "寒武纪 是什么股票" |

## Agent 流程说明

1. 💭 **思考中**: Agent 正在分析问题、决定调用哪些工具
2. 🔧 **工具调用**: Agent 正在执行分析（个股/持仓/大盘等），显示加载状态
3. ✅ **工具完成**: 工具执行完毕，显示结果摘要
4. 🤖 **最终回答**: Agent 综合所有工具结果，给出完整的 Markdown 回答

## 报告保存

Agent 回答后，每条消息右上角有两个导出按钮：

- **💾 MD**: 保存为 Markdown 格式
- **🌐 HTML**: 保存为带样式的 HTML 格式

**文件位置**: `~/Documents/衡势价值/智能分析报告/`

## 故障排查

| 问题 | 原因 | 解决 |
|------|------|------|
| API Key 错误 | LLM 配置无效 | 到"设置"页检查 LLM 配置 |
| 响应慢 | 多步分析耗时 | 正常情况 15-60 秒 |
| 看不到会话 | 数据库问题 | 刷新应用 |
| Agent 卡住 | 网络或 LLM 超时 | 稍后重试 |
| 导出失败 | 目录权限 | 检查 `~/Documents/衡势价值/` 是否存在 |

## 注意事项

- Agent 回答仅供参考，不构成投资建议
- 建议在提问时明确股票代码或名称，避免歧义
- 长时间未操作，会话可能因超时断开
- 单次最多 5 步推理，防止无限循环
