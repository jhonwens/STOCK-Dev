# STOCK ANALYST — 架构设计文档

## 一、产品定位

**AI 股票分析助手**，不是传统股票软件。核心价值：
- 自动分析**持仓股票**的卖点风险、止损建议
- 自动分析**候选股票**的买点机会、买入建议
- 输出结构化 + LLM 驱动的深度分析报告
- 遵循技术面+基本面+经营分析三维框架


### 核心通信机制

| 通信方式 | 场景 | 说明 |
|---------|------|------|
| Tauri invoke | 前端 → Rust | 高频查询（股票列表、指标数据） |
| Rust → SQLite | 直读数据库 | 避免每次启动 Python |
| Rust spawn sidecar | 调用 Python | 数据爬取+分析计算+LLM |
| Python → stdout | 返回 JSON | sidecar 结果解析 |

## 五、技术指标计算规则

### 5.1 均线系统（葛兰碧八大法则）
- EMA20, EMA60, EMA120
- 金叉: 短期上穿长期
- 多头排列: EMA20 > EMA60 > EMA120 且三条线向上

### 5.2 MACD
- DIF: EMA12 - EMA26
- DEA: DIF 的 EMA9
- 柱: (DIF - DEA) × 2
- 顶背离: 股价新高, MACD 波峰降低

### 5.3 KDJ
- K, D, J 三线
- 超买: J > 80
- 超卖: J < 20

### 5.4 RSI(14)
- 超买: > 70
- 超卖: < 30

### 5.5 布林带(20,2)
- 中轨: MA20
- 上轨: 中轨 + 2σ
- 下轨: 中轨 - 2σ

### 5.6 OBV
- 累积成交量（涨加跌减）

### 5.7 趋势过滤四步法
1. **定方向**: EMA20/60/120 多头? 空头?
2. **看阶段**: MACD 背离? 健康?
3. **评估能量**: K线实体饱满? 重叠少? 缺口未补?
4. **确认级别**: MACD 与零轴关系

### 5.8 缠论三类买卖点
- 一买/一卖: 本级别背驰点
- 二买/二卖: 回踩/反弹确认点
- 三买/三卖: 中枢突破后回踩不返回

## 六、LLM 集成

### 6.1 角色定位
**LLM 做解读，不做计算。** Python 规则引擎负责所有确定性计算，LLM 负责综合解读、报告生成、问答交互。

### 6.2 调用场景
| 场景 | 触发方式 | 上下文注入 |
|------|---------|-----------|
| 综合报告生成 | 用户点击"生成报告" | 全量持仓+候选+指标+预警 |
| 个股深度分析 | 个股详情 Tab 点击"LLM分析" | 单只股票全维度数据 |
| 聊天问答 | 全局浮窗输入问题 | 当前页面上文 |
| 快捷提问 | 预置按钮 | 对应场景上下文 |

### 6.3 配置（设置页弹窗）
- API Base URL
- API Key
- 模型名称
- Temperature 滑块

## 七、安全设计

| 风险 | 应对 |
|------|------|
| API Key 泄露 | 存储到配置文件，不写死代码 |
| 数据隐私 | 所有数据本地 SQLite，不上传 |
| Python 进程安全 | 沙箱运行，限制文件系统访问范围 |
| LLM 提示词注入 | 系统 prompt 约束，用户输入仅作为消息内容 |
